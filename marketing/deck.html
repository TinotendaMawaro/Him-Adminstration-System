Security & trust

Built to be safe for a church family

🔑

Access control

Role-based access on the server for every action. Tokens, rate limits and account lock-outs protect sign-in.

🛡

Safe content

Photos are checked by content. Only YouTube, Vimeo and https images can be embedded. Several reports auto-hide a post.

🪪

Verifiable ID

Each card’s QR code carries a signed link that confirms the card is genuine without exposing private details.

📜

Audit trail

Moderation and administrative actions are recorded and the people affected are notified.

🔒

Encrypted

HTTPS everywhere and a TLS-encrypted cloud database.

💳

Secure payments

Online giving is handled by the ClicknPay gateway; card details never touch our servers.

Under the hood

Modern, scalable and easy to run

Apps

React + Vite web app, installable as a PWA, packaged for Android with Capacitor.

Back end

Laravel 11 API with Filament admin consoles for Master, Finance and Events.

Cloud

Vercel hosting, TiDB Cloud database, Vercel Blob for photos and Resend for email.

Same database and same logic for every portal and the mobile app. A daily scheduler sends reminders and housekeeping.
